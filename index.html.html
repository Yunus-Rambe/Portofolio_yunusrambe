Project Manager — Sistem Monitoring Penerima Beasiswa Berbasis Web
Jan – Feb 2026
PT. Semen Padang (BUMN) · Magang · UPZ Semen Padang
Melaksanakan kerja praktik di Unit Pengumpul Zakat PT. Semen Padang dengan fokus pada pengembangan sistem informasi Program Beasiswa Anak Binaan berbasis web. Terlibat dalam analisis proses bisnis, identifikasi permasalahan sistem manual, serta perancangan dan pengembangan sistem menggunakan pendekatan terstruktur.
